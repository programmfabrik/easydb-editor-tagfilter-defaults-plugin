# easydb-plugin-tag-defaults
Plugin to set simple text field defaults depending on a tag filter.

This is a frontend only plugin, it can be used in [easydb5](https://docs.easydb.de/en/sysadmin/configuration/easydb-server.yml/plugins/tagfilter/) and [fylr](https://docs.fylr.io/plugins/overview#easydb-editor-tagfilter-defaults-plugin).
